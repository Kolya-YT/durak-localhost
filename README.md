# Дурак LAN

Мобильная 2D-игра «Дурак» для Android с локальной игрой по Wi-Fi или точке доступа без внешнего игрового сервера.

## Технологии

- Godot 4.4.1, GDScript.
- ENet host/client через ENetMultiplayerPeer.
- UDP broadcast для поиска комнат в одной локальной сети.
- Авторитетная логика на хосте.
- Колода 36 карт, 2–4 игрока, подкидной режим и кнопки взятия/отбоя.

## Сборка APK

Push в main запускает GitHub Actions при изменении игровых файлов или workflow. Ручной запуск доступен во вкладке Actions → Build Android APK → Run workflow.

После успешной сборки откройте завершённый запуск workflow и скачайте артефакт durak-lan-debug-apk. Артефакт доступен 14 дней.

## Локальная игра

1. Установите APK на телефоны Android.
2. Подключите телефоны к одной сети Wi-Fi или к точке доступа одного из телефонов.
3. На одном телефоне нажмите «Создать комнату».
4. На остальных выберите найденную комнату.
5. Хост нажимает «Начать игру».

Некоторые точки доступа блокируют broadcast между клиентами. В такой сети автообнаружение может не работать.

## Примечания

Это ранний прототип, требующий проверки на реальных устройствах и дальнейшей отладки правил. Для iOS нужна отдельная сборка; Android APK на iPhone не устанавливается.
